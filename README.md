# practice-using-adv-sql-2-saunders-quimeka

During this exercise, I learned how the order of execution in SQL changes how data is filtered, specifically realizing that the `WHERE` clause filters individual rows before grouping happens. The most challenging part was understanding why Customer #1 was missing from the filtered query, which helped me see the clear difference between using `WHERE` for raw data and `HAVING` for aggregated totals.
